## Run it

```bash
pnpm install
pnpm run dev       # http://localhost:5173
```

## Build for production

```bash
pnpm run build
pnpm run preview   # serve the built dist/
```

## Layout

```
.
├── index.html          ← Vite entry
├── src/
│   ├── main.ts         ← mounts the app into #app
│   └── style.css       ← global styles
├── package.json
├── tsconfig.json
└── vite.config.ts
```

Add components as separate files under `src/components/`, data helpers
under `src/lib/`, and wire them in from `main.ts`.
