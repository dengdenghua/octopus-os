# 桌面与工作台 UX 优化清单

目标：桌面与工作台是同一套应用的两种宿主形态。应用、文件、任务、模型和权限共用身份与状态；普通 `/workspace/*` 链接按兼容规则进入桌面窗口，明确标记 `presentation=workbench` 时保留全屏工作台入口。

参考 QwenPaw 的能力组织方向，不将其未实测的交互当作已验证方案。本清单以本项目现有实现为准。

## P0：应用身份与打开方式

- [x] 内置应用中心和侧栏共用应用登记表中的身份与路由。
- [x] 本地数据库作为一个系统应用；分类留在应用内，独立窗口与工作台复用内容。
- [x] 应用中心、数据库窗口、侧栏编辑共享固定偏好。
- [x] 侧栏隐藏只移除入口：删除根据侧栏偏好重定向页面的旧路由守卫，适用于所有工作台应用。安装、运行时就绪和权限检查继续由各自边界处理。
- [x] 系统应用卡明确区分“独立窗口打开”和“在工作台中打开”；仅对支持独立窗口且宿主提供打开能力的应用显示该选项。
- [x] 数据库从独立窗口进入工作台时携带当前分类与查询参数。
- [x] 将统一的打开方式选择扩展到远程应用卡、Dock 和搜索结果，依据实际宿主能力显示操作。
- [x] 安装、禁用、卸载通过账号隔离的同源可用性事件即时同步到全部宿主；后端不可用时未知状态保持不可用。

验收：同一应用从任一入口打开，身份一致；取消固定后仍能从应用中心打开；卸载保留数据的语义独立于取消固定。

## P1：桌面窗口与任务接续

- [x] 删除旧的侧栏强制重定向和重复宿主状态；旧链接、登录回跳、引导、数据库与应用中心按兼容规则进入桌面窗口，明确工作台入口继续可用。
- [x] 桌面与工作台宿主按身份分别保留路由和草稿；在两个宿主间往返不会清空草稿。登录完成前保留待打开链接，打开后清除一次性参数。刷新后的全量窗口恢复仍不在本项范围内。
- [ ] 桌面任务面板已存在；逐项验证运行中、等待确认、失败、已完成状态与会话一致。
- [x] 使用原始任务和会话标识接续任务；统一桌面任务窗口身份，重复打开聚焦已有任务。
- [ ] 完成结果可直接打开文件或定位原始产物；失败能回到可恢复的步骤。

验收：切换不创建第二个任务，不重发提示，不遗失待确认操作。当前数据库分类跳转不代表完整任务或编辑状态接续已经完成。

当前补强：任务投影会从 Agent 的线程工作区发现最多 20 个 `final`/`deploy` 产物，以资源身份展示并从任务详情打开原线程；失败、断开和取消状态会显示结束原因。恢复步骤和真实 Agent 运行态仍需现场验收，因此本项保持未完成。

## P1：统一文件工作区

- [x] 本地数据库的独立与内嵌界面共用内容组件及现有数据接口。
- [ ] 浏览、预览、编辑、差异查看、引用统一使用文件资源标识。
- [x] 对话附件与数据库文件之间提供双向定位，避免产生无法追溯的副本（本地数据库资源支持路径或仅资源 ID 引用）。
- [ ] 验证文件授权范围在桌面、工作台和 Agent 工具调用间一致。

当前补强：工作区输出列表和 `locate` 响应会返回同一枚 `workspace-file:v1` 资源身份，也可通过 `/api/workspace-resources/{resource_id}` 走同一授权边界读取；预览、下载、HTML 编辑和版本恢复已使用该入口。身份由线程、区域和工作区内相对定位组成，不携带主机绝对路径；本地数据库的浏览、预览、引用及对话双向定位已保留 `appliance-file:v1`/`storage-file:v1` 身份，Electron 原生桌面在 Storage sibling 不可用时也通过同一 JWT 提供专属文件根目录的读取回退。只有外部 Storage 服务的 browse/read/edit/diff 端点尚未在本仓库内统一，因此本节仍保持未完成。桌面缺少 Storage 路由时，browse 的路由级 404 已降级到同源文件读取回退；Storage 客户端回归 **13 项通过**。

验收：Agent 修改的文件可在数据库中定位到同一资源；无权限时两个入口都准确解释原因。

## 安装状态同步补强

安装可用性缓存及合并请求已按当前账号隔离；账号变化立即隐藏旧可用性，后续读取不复用旧账号请求，旧响应与旧快照不得发布到新账号。安装、启用、停用、卸载后的快照通过不落盘的同源事件脉冲同步到其他桌面窗口，后端重新校验仍是权威来源；相关界面和状态测试通过，类型检查通过。补齐另一桌面目录的数据库图标映射，恢复非内嵌工作台的模型状态入口及返回桌面按钮。

当前实现已恢复双形态宿主：`presentation=workbench` 显式进入工作台，旧 `shell=workbench` 仍按兼容规则进入桌面窗口；`RetainedShellRoutes` 按账号保留两侧路由、查询和草稿。真实运行任务、待审批任务、原生 Electron 宿主和刷新后的持久化行为仍需实际验收。

已补充回归覆盖：新安装快照不会被旧启动请求覆盖；持久状态已卸载、禁用或损坏时，旧运行时进程不能使应用重新可用；库存校验失败时撤销远程应用的旧可用状态，系统内置应用仍可访问；安装、启用、停用、卸载结果通过账号隔离的同源事件同步到其他宿主。跨宿主真实服务交互仍需现场验收。

显式工作台草稿往返及旧链接兼容回归通过；任务级 Codex 模型覆盖、类型检查和 Vite 生产构建通过。真实运行中的任务、待审批任务、原生 Electron 宿主和刷新后的持久化行为仍需实际验收。

## 数据库引用接续

文件定位现同时携带原始产物引用；数据库提供“返回原产物”，回到原线程并打开同一个 workspace-output 区域及相对路径。链接使用 URLSearchParams 保留特殊字符，页面按线程与引用去重，避免重新渲染反复打开。Unix 路径中的字面反斜杠不再被转换成目录分隔符，目录定位与标识比较共用该规则。定位和数据库相关 16 项测试、类型检查通过。返回原产物的真实会话加载仍待浏览器验收，未视为统一资源 ID 已完成。

数据库本机文件行增加显式引用按钮：由任务产物定位进入时显示“引用到原任务”，将原路径加入原线程待发送附件并返回原会话；普通打开时显示“引用到助手”。目录不显示引用按钮。路径引用保留文件名原始空格，不复制文件或自动发送。移除目录读取成功后仍宣称离线的状态文案。文件定位、引用收件箱及输入框 56 项测试和类型检查通过。该闭环已覆盖路径引用，完整统一资源标识与浏览器交互验收仍待完成。

工作区 `workspace-output` 产物的定位现通过原 outputs 接口的 `locate=true` 读取已授权文件位置，共用线程归属、路径越界和文件存在检查；定位响应禁止缓存，不读取文件内容。前端验证响应线程身份，读取失败不猜路径，用户关闭或切换产物后不执行迟到的导航。后端工作区接口 8 项、前端定位和产物预览 8 项通过，类型检查通过。本项补齐工作区产物到数据库的定位，跨入口统一资源标识及完整授权/浏览器验收仍未完成。

绝对路径产物预览增加“在本地数据库中定位”，使用 URLSearchParams 保留文件名中的空格、中文、# 和 %。数据库本机视图读取原目录并标出、滚动到原文件，保留返回原任务链接；Windows 盘符、Unix 根目录和 UNC 共享根的面包屑及上级导航保留真实路径。目录读取失败清空旧内容并显示服务或权限错误，移除虚构常用目录及文件数量。定位相关 10 项测试和既有产物预览 6 项测试通过，类型检查通过。

范围限制：本轮定位适用于绝对路径文件，仍通过已有目录接口检查访问权限；workspace-output 引用不会猜测绝对路径，尚需服务端资源解析与统一身份通路。浏览器实际运行与完整双向定位验收仍未完成。

文件详情、预览及搜索结果引用统一经过内存文件收件箱，取消原先固定等待 350 毫秒发送事件的实现。目标会话输入框挂载或恢复后领取原文件路径，既不上传文件也不自动发送任务。队列按当前账号及明确线程标识匹配，领取后删除，未被领取的引用五分钟后失效；无目标线程的输入框不能领取其他线程的文件。回归覆盖冷启动挂载、一次领取、账号隔离、过期及用户确认发送。

本项解决引用传递时序；数据库与产物的统一资源 ID、双向定位和全链路授权验收仍需继续落实，不以路径队列替代这些要求。

本轮继续补齐统一身份基础：NAS 文件管理器的目录条目与上传、移动、恢复结果现在带有脱离宿主绝对路径的 `appliance-file:v1` 资源 ID；服务端提供按该 ID 下载的入口，并复用现有登录、数据范围和审计边界。工作台文件引用和本地数据库引用收件箱会透传可用的 `resource_id`，对话中的 `<referenced_files>` 仅在服务端提供身份时增加该字段，旧路径引用保持兼容。通用存储服务的浏览和索引结果仍需在服务端补发同类身份，数据库双向定位与真实 Agent 工具解析尚未视为完成。

统一身份继续向 Storage sibling 服务扩展：共享协议新增 `storage-file:v1`，前端在 browse/search 返回 `source_id` 时可派生稳定身份，Agent 的 `search_documents` 也会透传服务端身份或按 source/path 补齐身份；带身份的引用会进入经过服务端清洗的 `turn/start` `context_files` 元数据。Storage 服务本身仍是独立安装包，尚未在本仓库内改造其 browse 响应和资源读取端点，因此跨服务的双向打开仍需 Storage 版本配套后再验收。
