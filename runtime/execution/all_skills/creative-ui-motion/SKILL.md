# UI 动效广告

先确认真实界面、关键任务与品牌动效语气。所有功能演示必须保持产品逻辑正确，不能为了画面好看伪造不存在的操作。

输出包括：叙事结构、关键状态、界面镜头表、光标或手势、缩放与转场、字体与标注、品牌收束、实现建议和验收清单。动效优先解释层级、因果和状态变化；装饰性动效不能遮挡任务。

每个操作前给出视觉预告，操作后保留足够时间让用户看清结果。检查触点位置、状态连续性、安全区、录屏清晰度以及横竖屏适配。

这是 Echo 原创技能，不包含第三方私有 UI 动效模板。
