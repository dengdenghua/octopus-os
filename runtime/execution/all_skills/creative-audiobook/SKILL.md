# 有声书制作

保留作者语气与叙事视角，先完成章节切分、旁白和对白标注、角色表与发音词典，再决定音色和表演强度。

交付包括角色声音卡、逐段表演意图、停连与重音、环境声边界、章节文件命名、响度目标和错读/漏读/串角检查。未经授权不得克隆真人音色。
