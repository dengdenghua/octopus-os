# 梦核与阈限空间

先确定情绪是怀旧、安宁、迷失还是不安，再建立一条自洽但略有偏差的空间规则：重复尺度、错误出口、过度整洁、时间停滞或熟悉物件错位。每个异常都服务情绪，不堆砌随机诡异元素。

输出空间平面关系、色温与曝光、材质老化、标识系统、关键静帧、漫游路径和环境声层。镜头应提供进入、辨认、异常升级和余韵四个阶段，并维持门窗方向与光源连续。涉及“后室”等既有网络文化时只使用通用空间语法，不复制受保护角色或具体关卡资产。
