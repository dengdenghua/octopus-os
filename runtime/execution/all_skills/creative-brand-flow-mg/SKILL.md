# 品牌流线 MG 动效

从品牌标志提取曲率、角度、节点和主辅色，建立流线的出生、分叉、追随、汇聚与消散规则。若存在 IP 角色，让角色承担引导视线的功能，而不是作为无关装饰。

先画关键构图和路径，再分配速度曲线、层级、遮挡、发光与粒子密度。最终所有流线必须有动机地收束到品牌信息。输出路径草图、镜头时间表、图形规范、声音节拍和循环/非循环版本验收项。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
