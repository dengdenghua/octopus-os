# 有意低模影像

“失败感”必须是可重复的视觉系统：低面数轮廓、有限贴图、错误但一致的关节权重、阶梯帧率、硬切补间和略显笨拙的相机，而不是随机破坏或真正不可用的文件。先确定主体识别锚点，再选择两到三种缺陷贯穿全片。

交付原始低模关键帧、模型/材质约束、动作节拍、相机路径、声音方向和可读性下限。脸部、标志和关键动作仍需清楚；闪烁、快速抖动和音量突变要提供强度控制。不要冒充真实软件故障，也不要通过破坏文件制造效果。

这是 Echo 原创技能，不包含第三方私有提示词或视觉资产。
