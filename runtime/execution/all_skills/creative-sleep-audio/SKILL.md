# 助眠音频

先确认用途、时长、是否需要人声以及用户不喜欢的声音。结构从注意力安放逐步过渡到低事件密度，不使用突然的音量、尖锐高频或强节拍。

输出时间轴、旁白文本、呼吸间隔、环境层、循环点、淡入淡出和响度建议。不要宣称治疗失眠或替代医疗建议。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
