# 躲避游戏反应视频

先从参考图锁定面部、发型、服装、比例和正面待机姿态，再生成左、右、下蹲和跳跃四个动作关键帧。所有动作保持相同相机、地面线、光线和角色尺度，保证可在剪辑中无跳变切换。

设计障碍物预警、输入提示、成功/失败反馈、分数节奏和音效，但不要遮挡角色动作。输出状态机、关键帧清单、时间轴和透明背景素材规格；逐帧检查肢体连续、方向一致与碰撞时机。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
