# 多角度渲染

先标记参考中可见事实与不可见推断。固定主体比例、材质、标志位置和光线基准，再改变相机方位；不可见区域需明确采用保守补全。

输出视角列表、相机方位、焦段、背景、身份锚点和跨视角一致性检查。不要把推断结果描述为原物真实结构。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
