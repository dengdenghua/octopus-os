# 动画风格锻造

用线条粗细、人体比例、面部抽象、色块层级、阴影方式、背景密度和运动规律定义风格，而不是依赖艺术家姓名。

输出风格卡、角色适配、场景适配、表情与动作样张要求、不可变锚点和漂移检查。所有示例应形成可复用但原创的视觉规则。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
