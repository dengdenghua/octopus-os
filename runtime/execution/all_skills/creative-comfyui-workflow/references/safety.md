# 安全与依赖边界

- Bridge 只允许 `127.0.0.1`、`localhost` 或等价 loopback 地址。
- 引擎安装、稳定版更新、节点扩展安装/更新/卸载/回滚和模型下载/移除/恢复属于用户界面动作，不注册为 Agent 可写工具。
- 模型链接必须由用户逐项提供并确认；拒绝带账号密码、token 或 API key 查询参数的 URL。
- 工作流不得读取画布项目之外的任意路径。文件输入使用 Bridge 返回或用户明确选择的受控资产。
- 扩展执行第三方 Python 代码。依赖未核实或服务正在运行时，不建议改变扩展集合。
- 不把离线、未知或“未完整检查”转换为通过状态。
