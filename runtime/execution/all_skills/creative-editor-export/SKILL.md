# 剪辑工程导出

导出前核对目标编辑器、分辨率、帧率、色彩空间、音频采样率和字幕格式。将引用媒体统一收集，避免绝对路径、离线素材和重名覆盖。

交付工程描述、媒体清单、轨道映射、字体与效果替代说明、代理/原片关系和校验摘要。若目标格式不支持某种转场或效果，明确列出烘焙与可编辑两套方案。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
