# 技能课程详情页

从目标学员、学习前提、可验证成果、课程模块、讲师证据和购买顾虑建立信息漏斗。首屏只回答“学什么、为谁、完成后能做到什么”，随后依次呈现成果样例、课程地图、教学方式、讲师可信度、学员证据、价格与常见问题。

输出桌面和移动端线框、真实文案长度、组件状态与视觉方向。不要用虚构成绩、人数或评价填充证据；缺失内容用明确待补字段。关键行动按钮在首屏、证据段和价格段出现，但不以倒计时或虚假稀缺制造压力。

这是 Echo 原创技能，不包含第三方私有页面、文案或品牌资产。
