# 音乐卡点剪辑

先识别段落、主拍、切分音、重音和情绪峰值，再让镜头变化服务内容，不把每个拍点都机械切开。

输出带时间码的音乐结构、镜头入出点、动作匹配、变速区、转场理由和音效补强。优先在动作完成、视线改变和语义转折处落剪，避免连续同景别和无动机闪切。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
