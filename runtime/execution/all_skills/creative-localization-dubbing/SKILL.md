# 多语言配音与字幕

先识别角色、对白段、背景音、专有名词、文化语境和平台限制。翻译以人物意图和口语自然度为先，在不改变事实与剧情的前提下控制音节长度；建立术语表和角色声音表。

逐句输出源文、目标文、情绪、语速、停顿、预计时长和口型风险。不得在没有授权时克隆真实人物音色。交付分离对白、混音、字幕文件和差异报告，并验收人声清晰、角色一致、句尾落点、字幕断行和背景音乐衔接。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
