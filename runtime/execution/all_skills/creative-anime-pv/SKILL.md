# 动画游戏 PV

先锁定一个核心卖点和一句观众记得住的情绪承诺，再进入镜头设计。不要把世界观介绍、角色介绍和玩法介绍平均分配时长。

交付内容应覆盖：核心概念、时长与画幅、节奏段落、逐镜头目的、画面提示、声音提示、角色与场景一致性锚点、最终检查项。

短片默认采用“钩子—展开—升级—标志性收束”结构。每个镜头必须承担新的信息或情绪变化；相邻镜头若没有变化，应合并。生成前列出角色外观、服装、道具、时间与色彩的不可变约束。生成后检查角色漂移、动作方向、景别重复、文字可读性和音乐落点。

这是 Echo 原创技能；只借鉴通用影视制作范式，不包含第三方产品的私有提示词或源码。
