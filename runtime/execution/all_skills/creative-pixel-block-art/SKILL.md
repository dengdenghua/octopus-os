# 像素方块画

先选择目标网格尺寸和可用材料，再按轮廓、明暗大面和识别特征逐级简化。小尺寸优先保住剪影与对比，不追求噪声细节。

输出网格图、颜色编号、材料统计、分层搭建顺序和远距离可读性检查。对复杂渐变提供有限色抖动方案，并标记无法稳定表达的细节。
