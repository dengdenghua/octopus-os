# 3D 动画短片

先锁定时长、画幅、受众、视觉风格与情绪弧线，再建立角色比例、服装、材质、场景尺度和光照规则。输出角色卡、场景卡、逐镜头表、机位与焦段、角色动作、镜头运动、声音节拍和合成验收表。

镜头之间保持角色身份、空间朝向、光源方向与尺度连续。每个镜头都说明开始姿态、结束姿态和切点；复杂动作拆成可生成或可在导演台编排的短段。先用低成本预演验证节奏，再进入高质量生成。
