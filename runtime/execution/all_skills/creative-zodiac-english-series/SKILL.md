# 文化角色英语启蒙系列

把文化角色体系做成可持续剧集，而不是十二个互不相关的短片。先定义年龄、目标词汇量、核心句型、发音变体和每个角色的性格/动作/道具，再建立一集一个语言目标的故事与儿歌双轨结构。

每集控制新词数量，使用间隔重复、可预测问答和动作记忆；文化信息应准确、尊重且可由家长解释。交付系列圣经、角色表、季度词汇矩阵、单集脚本、歌词、画面节拍和学习验证题。避免把口音、文化符号或动物性格做成贬损刻板印象。

这是 Echo 原创技能，不包含第三方私有故事或歌曲。
