# IP 潮玩六宫格动态海报

从角色参考锁定脸部、发型、服装配色、标志性配件和不可变化特征，再建立同一材质与灯光下的六个姿态或情绪格。所有格子保持统一相机体系和角色比例，同时通过姿态、道具或背景色形成差异。

先交付静态六宫格确认身份一致和版式，再设计逐格点亮、角色轻动、镜头推拉与最终整体定帧。文字使用确定性排版层。输出角色锚点、六格清单、3D 材质、动态时间表、竖版安全区和社媒压缩验收。
