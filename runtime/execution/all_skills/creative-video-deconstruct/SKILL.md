# 视频逆向拆解

先区分可观察事实与推测。没有完整视频、音频或时间码时，明确证据限制，不虚构镜头细节。

按时间段记录：景别与机位、主体动作、构图、光线、色彩、材质、文字、转场、声音和信息目的。随后提炼节奏曲线、重复规则、变化规则、制作管线和最小可复现方案。

交付既要说明“它做了什么”，也要说明“为什么有效”和“如何在不复制具体作品的前提下复用方法”。最终列出版权敏感元素、可迁移的抽象规则、需要实拍或生成的资产，以及验证方式。

这是 Echo 原创技能，不用于复制受版权保护的具体画面或私有提示词。
