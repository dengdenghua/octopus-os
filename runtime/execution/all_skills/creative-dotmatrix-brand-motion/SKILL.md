# 点阵品牌字形动效

读取标志轮廓、品牌名、标语和目标画幅，建立固定点阵网格、最小笔画、字距和安全区。先完成静态品牌锁定，再设计点亮、扫描、聚合、拆分和尾帧停留。

所有文字必须来自确定的矢量或排版层，不能依赖生成模型猜字。点阵运动保持节奏可数、关键字可读、Logo 轮廓不漂移。输出静态主视觉、动效时间表、颜色与发光参数、横竖版适配和可读性验收图。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
