# 影视镜头与角色卡

每张镜头卡必须说明戏剧目的、主体动作、机位关系、焦段、景深、光线、声音和前后镜头连续性。角色卡记录外观锚点、内在目标、习惯动作和表演禁区。

避免只堆砌“电影感”形容词；用可拍摄、可生成、可复核的参数表达。输出编号卡片、轴线图和连续性风险。
