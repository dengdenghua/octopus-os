# 丝印装饰插画短片

先确定主轮廓、装饰母题、三到五个专色、纸张底色与套印偏移尺度。把镜头拆成底版显影、色层叠加、纹理滚入、主体运动和最终构图停留，保持每一层都能作为独立印版成立。

运动应服从印刷结构：色块滑移、网点扩散、刮板推进和轻微错版，而不是普通三维粒子。为每个视觉动作匹配纸张、刮擦、压印或器乐节拍。输出色版表、镜头表、循环点和无声版/配乐版验收项。
