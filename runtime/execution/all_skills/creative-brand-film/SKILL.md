# 品牌宣传短片

先区分品牌广告与产品广告：前者优先建立心智和情绪，后者优先证明利益点。若需求混合，明确主目标并让次目标只做支撑。

制作时依次形成：受众与场景、单一传播命题、品牌视觉锚点、三条创意路线、选定路线的镜头表、产品真实性约束、声音策略、渠道变体和验收清单。

产品外观、Logo、包装文字和功能演示不得凭空改写。信息密度随渠道调整，但主视觉和品牌动作保持一致。最终检查开头三秒是否成立、产品是否被看清、品牌是否在无声播放时仍可识别、结尾行动是否明确。
