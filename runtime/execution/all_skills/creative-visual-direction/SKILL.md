# 视觉风格导演

把模糊风格词改写为可观察的视觉属性。至少明确构图、镜头、光线、色彩、材质、空间、字体和运动八个维度中的必要项。

先提取参考图的事实，再总结风格规则；不要把作者名或平台名当作完整风格。输出一份“必须保持 / 可以变化 / 禁止出现”的约束表，并给出主提示、负向约束和三种强度变体。

生成后从轮廓、比例、材质、配色、光向和文字六方面复核。若结果漂移，优先修正矛盾的属性和过多的风格词，而不是继续堆提示词。

这是 Echo 原创技能，不包含第三方风格库文本。
