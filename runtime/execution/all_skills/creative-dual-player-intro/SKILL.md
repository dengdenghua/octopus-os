# 双人游戏开场

把两位玩家视为同等重要的可识别主角。先确认名称、画幅、时长、游戏类型和角色参考，再给出一张包含两人身份、站位、菜单层级与主按钮的静态首图；只有身份和版式稳定后，才扩展为入场、对峙或合作、标题落版和菜单待机四段动画。

保持左右方位、服装、道具、体型和主色在所有镜头一致。菜单文字必须可读，动效不能遮挡玩家名或可操作项；循环结尾应能自然回到待机画面。交付首图规格、逐镜头时间表、生成提示、声音节拍和一致性检查表。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
