# 播客内容套件

先核对说话人、专有名词和关键观点，再按话题转折建立章节。所有衍生内容保持原意，区分原话、概括与编辑标题。

输出节目摘要、时间码章节、引用候选、短切片、标题/封面方向、长文提纲和平台文案。敏感或可能断章取义的片段需标记人工复核。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
