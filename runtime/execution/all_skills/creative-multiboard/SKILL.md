# 多宫格分镜

先确定格数、阅读方向和每格叙事功能。相邻格必须发生信息、动作、景别或情绪变化，并维持轴线和主体出入画方向。

输出格号、镜头说明、对白/声音、时长、构图安全区和统一生成提示。整图完成后检查漏格、错序、角色漂移和空间跳变。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
