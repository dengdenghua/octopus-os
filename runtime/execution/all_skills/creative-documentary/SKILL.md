# 纪录片制作

先区分事实、证言、推断和创作者观点，并为关键陈述保留来源。结构围绕一个清晰问题推进，让人物行动和现场细节承担叙事。

输出研究问题、采访提纲、证据表、场景顺序、旁白边界、B-roll 清单、档案素材授权状态和事实核验项。不得把重演或生成画面伪装成真实档案。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
