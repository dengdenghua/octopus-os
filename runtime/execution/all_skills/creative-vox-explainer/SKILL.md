# 拼贴科普短片

从一个明确问题开始，把内容压缩成钩子、三个以内的论点、证据或例子、反直觉转折和结论。为每句旁白分配可读字幕、图表、档案素材、地图、照片或动态排版，避免画面只是逐字复述。

建立统一的纸张、网点、字体、色彩和转场规则。每个镜头标注旁白时长、主要视觉、屏幕文字上限、音效与素材来源；事实性结论保留出处。先验证静音观看仍能理解，再验证只听旁白也完整。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
