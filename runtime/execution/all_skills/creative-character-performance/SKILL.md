# 人物微表情与表演

先确定角色此刻知道什么、想得到什么、在隐藏什么，再按时间段描述视线、眨眼、眉眼、口角、呼吸、重心和手部动作。使用可观察行为而非抽象情绪词，并明确表演强度与禁止出现的夸张动作。

为每个镜头提供静止起点、情绪触发、细微变化、峰值和回落。保持身份、发型、服装、年龄、脸部比例与镜头光线稳定。验收重点是眼神方向、口型、呼吸节奏、左右一致和动作是否符合角色动机。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
