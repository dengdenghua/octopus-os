# 教育可视化工作室

先写出学习者完成后能够做什么，再决定讲解形式。每个段落只解决一个认知困难，并安排一次可观察的理解验证。

输出包括：学习目标、先备知识、误区、讲解结构、逐镜头图解、旁白、屏幕文字、示例、练习和答案依据。图像只服务于关系、变化或对比，不能作为无关装饰。

术语首次出现时用大白话解释；公式、数据和因果关系必须可追溯。检查旁白与屏幕文字是否重复、图解是否在旁白之前建立、练习是否真正检验目标而非记忆细节。

这是 Echo 原创技能，不复制第三方课程模板。
