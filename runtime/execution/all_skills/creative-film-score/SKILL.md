# 影视配乐

从叙事功能而非曲风标签开始：明确音乐是在揭示、掩饰、推动还是留白。为角色和概念建立可变化的短动机，避免全片持续铺满。

输出 cue 表、时间码、情绪功能、调性/速度、配器、动态弧线、对白避让和版本需求。引用风格时描述可观察的音乐特征，不要求复制在世艺术家的独特作品。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
