# 微短剧剧集编剧

先建立主角欲望、阻力、代价和持续冲突，再规划每集独立推进。开场快速给出异常或目标，集尾留下由人物选择造成的新问题。

输出季纲、角色弧、每集一句话、场次表、对白草稿、制作复用策略和连续性表。反转必须由已给信息支持，不依赖突然新增设定。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
