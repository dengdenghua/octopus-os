# 纸艺定格科普

先把知识点压缩为一条可验证的因果链，再为每个环节设计纸偶、前中后景、可替换标签和能在真实桌面完成的逐帧动作。优先使用推移、翻折、揭页、替换、旋转和遮罩，不用违背纸材重量与关节结构的漂浮运动。

交付材料表、统一色板、关键帧、每秒动作表、旁白、字幕和纸张摩擦/敲击音效。事实、术语和数值必须可追溯；文字在停留帧保持足够阅读时间。最后检查纸偶比例、光向、阴影、手作误差和场景连续性。
