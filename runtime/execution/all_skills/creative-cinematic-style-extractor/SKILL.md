# 电影风格规则提炼

把参考拆成可观察规则而不是只写导演或片名：画幅与构图重心、焦段和机位高度、景深、相机运动、主辅光关系、色彩分布、材质、剪辑密度和声音留白。区分单张剧照证据与整部影片推断，证据不足时明确标记。

输出风格规则卡、禁止项、三个原创场景测试和图像/视频提示。保留高层审美特征，但改变人物、地点、叙事、标志性道具和构图组合，避免逐镜复刻仍受保护的表达。若用户要求在世艺术家的直接风格模仿，改为描述可观察特征并生成非署名原创方向。

这是 Echo 原创技能，不包含第三方私有提示词或影片素材。
