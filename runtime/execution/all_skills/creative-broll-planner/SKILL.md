# B-roll 规划

按语义而不是固定字数切分口播，标记必须看见的事实、可用隐喻、人物反应、产品证明和应保留 A-roll 的段落。每条 B-roll 给出入点、出点、镜头内容、景别、运动、来源、版权状态和与旁白的关系。

不要让素材仅重复旁白字面内容；优先补充证据、空间、过程和情绪。生成素材前先提交低成本清单供确认。最终检查素材时长覆盖、人物和产品一致、版权可用、画幅可裁切，并保留无法视觉化的句子在 A-roll。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
