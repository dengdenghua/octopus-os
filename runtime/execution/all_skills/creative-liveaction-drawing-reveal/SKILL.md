# 实景动态手绘显影

先选取具有明确主体、景深和运动方向的实景素材，稳定相机并追踪主体轮廓。设计笔尖或线条的进入路径，使显影发生在主体真实位置、真实遮挡关系和真实运动上。

手绘层分为轮廓、结构线、强调线和颜色块，按时间逐层出现；避免把整张画面简单套滤镜。主体继续运动时，绘制层必须随跟踪点变形并保持接触。输出跟踪方案、显影路径、分层素材、音效提示和逐帧漂移检查。
