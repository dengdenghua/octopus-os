# 动态海报

先拆分背景、主体、装饰、标题、副标题、Logo 和行动按钮，标记必须完全静止或保持清晰的区域。根据原版式选择景深、遮罩揭示、局部粒子、光影扫描、轻微视差和字体动效，不改变信息层级。

输出分层清单、时间线、每层运动范围、缓动、循环接缝和声音建议。文字与 Logo 不做会破坏字形的生成式形变；主体不能漂移到影响识别。验收首尾可循环、文字全程可读、运动有主次且不同画幅裁切后仍成立。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
