# 场面调度与镜头语言

## Blockout 顺序

1. 以主角身高约 1.7–1.8 m 建立尺度参照。
2. 放置地面、主要空间边界和承担动作的道具。
3. 安排角色站位、朝向与视线；对话距离通常保持 1.2–1.8 m，再按景别调整。
4. 放置主机位，先验证主体轮廓和遮挡，再选择焦段。
5. 最后添加次要道具、背景和装饰。

## 相机选择

- 推近：信息或情绪逐步集中。
- 拉远：揭示环境、孤立感或关系变化。
- 横移：跟随行动或建立空间关系。
- 环绕：展示主体体积和关系，但避免无动机炫技。
- 升降：改变权力感、揭示空间层级。

镜头移动的最后一段应把注意力落到叙事目标。角色沿路径到达时，最后一段方向应与最终朝向一致，避免停止后瞬间转身。

## 姿态与接地

- 站立、行走和奔跑时脚底接地，尺度在同一镜头中保持不变。
- 坐姿的髋部高度与座面一致，朝向与座椅朝向一致。
- 驾驶姿态需检查身体是否穿出车体；封闭车体无法看见驾驶员时，不承诺可见表演。
- 角色离开载具后仍需自然比例时，不为了藏进车内而永久缩小角色。
