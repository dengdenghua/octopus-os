# 声明式程序化模型

目录里没有的可识别物件使用一个 `model_generate` 实体完成，不能拿语义不相关的道具冒充，也不要把多个独立道具拼成一个本应整体选择的物件。

## 搭建顺序

1. 列出主体包围盒、地面接触面和 3–8 个决定轮廓的主要部件。
2. 先用 box、sphere、cylinder、cone 完成灰盒，检查正面、侧面、俯视和等轴视图。
3. 修正比例、接触、朝向和轮廓后，再加入颜色、金属度与粗糙度。
4. 英雄物件使用同一个 `model_id` 原位迭代；背景物件只做一次低成本修正。

每个部件要有唯一、语义明确的名称。尺寸必须为正数，默认位置的 Y 值应让部件接触地面；生成结果出现 `UNDERGROUND`、`FLOATING` 或重复名称警告时先修正再进入场景。

`model_compare` 只用于参考图的轮廓与布局辅助，不能替代场景快照中的尺度、遮挡、材质和叙事判断。
