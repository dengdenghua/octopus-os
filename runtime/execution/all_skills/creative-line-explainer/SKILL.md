# 线条图解科普视频

把知识拆成对象、关系、状态变化和因果链，再决定哪些用线条角色表演，哪些用箭头、时间轴、剖面或对比图。每个镜头只解释一个关系，旁白与图形同时到达关键点。

建立统一笔宽、端点、图标语法、强调色和字幕层级。复杂过程先画静态关键图，再设计线条绘制、擦除、变形和镜头切换。输出逐句旁白、画面图解、动画指令、屏幕文字与理解检查题。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
