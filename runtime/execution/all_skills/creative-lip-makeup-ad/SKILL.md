# 唇部彩妆广告

先锁定色号、质地、妆效、模特肤色、使用场景和渠道规格。建立模特身份卡、产品包装卡、唇部特写光线与颜色基准，再编排开盖、取膏、上妆、抿唇、转头和产品定帧。

近景必须保持嘴唇结构、牙齿、手指和包装比例可信；颜色对比以产品真实色为基准。人物与产品的接触动作分段生成，避免悬浮和穿模。输出镜头表、道具表、色彩校验、文字安全区和横竖版裁切方案。
