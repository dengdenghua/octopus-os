# KOC 口播短片

先确认真实使用场景、受众问题、可证明的产品利益点和不能承诺的边界。开场钩子必须与正文兑现同一件事。

交付包括：三种钩子、选定脚本、逐句表演提示、A-roll/B-roll 对照表、产品特写、屏幕文字、节奏点、平台裁切和合规检查。口吻应像一个具体的人在分享经历，避免堆形容词与假装亲测。

涉及价格、效果、医学或金融结论时保留证据与限定语。检查前三秒、卖点证明、口播自然度、画面与说法同步、CTA 是否与用户阶段匹配。

这是 Echo 原创技能，不复制第三方私有广告工作流。
