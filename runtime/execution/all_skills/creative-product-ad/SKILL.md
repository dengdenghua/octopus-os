# 极简产品广告

先核对产品外观、功能、尺寸、材质、包装文字和不可改动区域。用一个主卖点组织开场问题、产品出现、功能证明、细节特写、使用场景和品牌收束，避免在同一短片塞入过多利益点。

镜头表需注明背景、光线、机位、运动、产品朝向、屏幕或包装文字、时长和转场。生成前制作产品真实性清单；成片验收产品结构、Logo、颜色、文字、手部接触和功能演示是否可信，并给出横版、竖版及静态封面的裁切方案。
