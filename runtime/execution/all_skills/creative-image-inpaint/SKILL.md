# 图片局部重绘

先确认编辑区域、希望保留的边缘和上下文，再为遮罩增加合理羽化。提示只描述需要改变的内容，同时锁定相机、光源、比例和相邻材质。

输出遮罩说明、正负提示、重绘强度、边缘融合策略和前后对比检查。不得静默修改遮罩外的身份、文字或商品细节。
