# 角色场景分镜资产

先建立角色身份锚点、服装版本、场景平面关系、关键道具和时间天气，再生成镜头。设定板需同时回答“是谁、在哪里、朝哪看、拿什么、前后镜头怎样连续”。

输出角色转面、表情、场景远中近景、道具比例、色彩脚本和编号分镜；对不可见或未经确认的信息使用占位说明，不擅自补写剧情事实。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
