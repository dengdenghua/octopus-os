# 多模态视频提示词导演

先确认交付时长、画幅、清晰度、是否生成声音，以及每份参考素材分别约束人物、场景、风格、动作还是声音。将需求整理为全局基准、主体身份、空间关系、镜头运动、分时动作、声音设计和负面约束。

不要把互相冲突的动作塞进一个镜头。人物一致性优先写稳定身份锚点；镜头控制优先写起点、终点、速度和焦点变化。输出一份可直接提交的主提示词，以及参数表和最小验收清单；若模型不支持某参数，改用其真实字段而不是猜测。

这是 Echo 原创技能，不包含第三方私有提示词或工作流文本。
