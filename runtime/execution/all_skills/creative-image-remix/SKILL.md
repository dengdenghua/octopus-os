# 图片重混

将参考拆成可复用的视觉变量：画幅、主体占比、空间层次、光源、色调、材质和镜头，不复制受保护角色、标志或独特构图细节。

输出保留项、替换项、负面约束、提示结构和相似度风险检查。若用户要求精确复制第三方作品，改为提供同类视觉语言的原创方向。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
