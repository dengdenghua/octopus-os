# 宣传视频

先确认受众、发布渠道、时长和唯一转化目标。将信息分为“问题、承诺、证据、行动”四类，只保留能被画面证明的卖点。

输出应包含一句核心主张、镜头表、产品事实来源、旁白与屏幕文字、声音设计、横竖版适配和交付清单。不得虚构功能、客户评价或性能数据；缺少证据时明确标记待确认。

这是 Echo 原创技能，不包含第三方产品的私有提示词或源码。
