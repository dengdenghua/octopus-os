# 电影片头设计

片头不是剧情摘要，而是让观众提前进入作品的规则与情绪。先从主题、时代、材质、运动和声音中选出一个可持续变化的母题。

输出包括：母题说明、视觉语法、字体与署名层级、镜头时间轴、转场规则、声音节拍、片名揭示方式和制作清单。字幕需要给出安全区、停留时间与背景对比要求。

避免每个镜头使用不同风格，也避免用随机故障、粒子或墨迹替代叙事。检查片名是否是最强视觉节点、署名是否可读、镜头节奏是否与音乐有因果关系、效果是否能在目标制作条件下实现。

这是 Echo 原创技能，不复制任何第三方片头模板。
