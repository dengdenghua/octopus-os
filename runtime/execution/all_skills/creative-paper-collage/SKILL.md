# 纸拼贴讲解动画

把内容拆成少量可视化论点，为每一段指定纸张层级、剪裁边缘、印刷纹理、手作运动和转场机关。先给出色板、纸材、字体、图形语法与一张关键帧，再扩展为逐镜头脚本。

运动保持手作物理感：平移、翻页、折叠、撕开、叠放和轻微错位优先，避免无来源的三维漂浮。声音以纸张摩擦、剪切、按压和轻量音乐支撑信息节奏。最终检查文字可读性、概念准确性与触感一致性。
