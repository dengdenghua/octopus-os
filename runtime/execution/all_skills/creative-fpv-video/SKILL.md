# 第一视角 FPV 穿越

先确认时长、画幅、真实无人机或幻想镜头、运动强度和终点。依据场景拓扑规划进入点、路径门、转弯半径、高度变化、遮挡转场和落点，避免只堆砌地点名。

按时间轴输出位置、朝向、速度、焦点对象和环境反应。加速用于建立期待，减速用于看清关键对象；狭窄空间需保留安全间隙和明确路径。成片检查路线连续、空间尺度稳定、没有瞬移穿模、滚转不过度且终点有视觉回报。
