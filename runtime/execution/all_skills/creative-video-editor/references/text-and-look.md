# 字幕、标题与画面风格

## 字幕与标题

- 字号按画布尺寸确定，不把某个像素值跨分辨率复用。优先使用项目预设统一整组字幕，再在真实最繁忙背景上检查可读性。
- 默认避开脸、嘴部、产品细节、屏幕 UI 和动作落点。底部拥挤时可改到顶部，但要抽查不同镜头，不能只看一帧。
- 一条字幕表达一个完整、可及时读完的意思。连续三行或长段通常说明切分粒度不对，应先重切字幕，再调整样式。
- 标题应补充画面无法直接表达的信息。显示时长按实际阅读量与节奏决定；不要因为接口有默认时长就机械使用。
- 同一作品的字幕样式应作为系统处理：字体、字号、颜色、背景/描边、位置保持一致，只有明确的角色或叙事区分才创建第二套规则。

## 调色与效果

- 先解决镜头之间的曝光、白平衡与饱和度一致性，再做风格化。风格统一建立在素材能自然连续的基础上。
- 每个效果都要有可说清的作用：暗角聚焦、颗粒统一质感、模糊分离背景。无法说明作用的效果应删除。
- 从小幅参数开始，用同一时间点的前后快照比较。极端色温、色调或对比度属于明确风格选择，不能作为普通校正默认使用。
- 当前渲染器对未完整合成的效果或转场会返回 `warnings[]`。遇到 warning 时只能报告结构已经写入，不能声称最终视觉成立；应在真实播放环境继续验收。

## 复核采样

视觉变化至少检查：变化前的稳定帧、变化发生处、变化后的稳定帧。字幕还要抽查最亮、最暗和主体最靠近字幕区的镜头；调色需用同一时间点做前后对照，避免被不同内容误导。
