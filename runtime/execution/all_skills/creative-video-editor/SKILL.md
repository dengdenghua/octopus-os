# AI 多轨剪辑

先读取项目，再做内容判断。不要从文件名猜素材内容，也不要在不知道片段、轨道和绝对时间的情况下生成编辑操作。

## 工作流

1. 调用项目读取接口；需要媒体路径或标记时使用完整视图。
2. 将同一用户意图的变更组成一个批次。涉及大量片段或高风险调整时先 `validateOnly`，验证通过后再提交。
3. 任何移动、裁切、分割、变速或删除后都运行时间线诊断。黑场和同轨重叠属于必须修复的错误。
4. 字幕、调色、效果或转场属于视觉变更；检查受影响时间点的真实预览帧，确认文字可读、主体不被遮挡且镜头衔接符合意图。返回 warning 的未合成效果不能当作已经视觉验收。
5. 需要交付成片时调用项目导出，确认 MP4 可解码、音轨符合预期且 `warnings[]` 已处理；不能用项目 JSON 或静态快照代替视频交付。
6. 将播放头停在结果附近，并用项目时长、改动范围和仍存在的警告总结交付。

详细接口和操作字段见 [references/api.md](references/api.md)。涉及镜头取舍、节奏、转场、静音压缩或变速时读取 [references/editorial-judgment.md](references/editorial-judgment.md)；涉及字幕、标题、调色与效果时读取 [references/text-and-look.md](references/text-and-look.md)。完成判定见 [references/verification.md](references/verification.md)。只读取当前任务需要的参考文件。

## 约束

- 所有时间使用项目秒数，不使用帧号或未经解析的时间码字符串。
- 轨道、片段和媒体 ID 必须来自项目读取结果；唯一前缀可用，不得编造。
- 用户点名轨道时按可见名称匹配；同名轨道不唯一时先澄清。
- 批量操作失败会整体回滚。根据失败项修正后重发完整批次，不要只补发剩余操作。
- 不自动导入用户未授权的外部文件，不覆盖其他项目，也不把依赖缺失包装成成功。

这是 Echo 原创技能，不包含 MiniMax 私有提示词或未授权实现。
