# 模拟炒股 · 复刻版(paper_trading_replica)

> 状态:**待打磨**(已从「模拟炒股」主插件拆出,停放在插件中心,暂不在工作台前端展示)。

## 这是什么

「模拟炒股」主插件(paper_trading)的前端已改为内嵌平台的**原版网页**(iframe,1:1、零维护)。
原来我们自己实现的 1:1 **复刻交易页**被拆到本插件,作为一个独立、可插拔的模块保留下来,
后续想继续打磨时直接从插件中心启用即可。

已实现的功能(都在本插件页面里):

- 平台交易页 1:1 复刻(左侧深色导航 / 自选行情 / 图表(分时·日·周·月·1·5·15·30分)/
  合约卡(真实字段) / 盘口五档 / 买入卖出面板 / 底部持仓·订单·合约明细)
- 自选列表 ★/☆ 星标增删 + 选中股名称旁星标
- 持仓行「买/卖」一键带入对应股票到交易面板
- 操作结果 toast 通知(下单/登录/自选/合约操作)
- 平台登录 / 申请资金 / 买卖二次确认,写操作全部 `confirm: true`

## 页面与后端

- 页面:`/api/plugins/paper-trading-replica/page`
- 后端:复用主插件 `paper_trading` 的 API(`/api/plugins/paper-trading/*` 行情/自选/平台配资交易),
  本插件只提供前端页面,不重复实现后端。
- 使用前请确保主插件 `paper_trading` 已加载(它提供行情与平台交易后端)。
