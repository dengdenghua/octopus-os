# Continuity review

Compare the target candidate with the branch's source-cited context pack. Check chronology, identity, location, knowledge, inventory, relationships, promises, world rules, planted clues, and state transitions. Separate a sourced contradiction from an inference or an unresolved question, and include the relevant source refs in every finding.

Return a candidate review or proposed state-change record only. Do not rewrite source facts as canon, vote on a review, clear a blocker, or create a CanonCommit. If context is truncated or lacks the necessary source, state that limitation rather than claiming certainty.
