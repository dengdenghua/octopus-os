# Narrative authoring

Use the project's selected branch and a bounded context pack as the source of truth. Preserve the requested voice, point of view, tense, language, and target length. Treat world facts and earlier chapter state as constraints, and cite their source refs in the candidate's supporting notes when available.

Create or revise only candidate artifacts. Never label prose as approved canon, cast governance votes, resolve blocking reviews, or create a CanonCommit. Surface contradictions or missing evidence for human review instead of silently inventing a resolution.
