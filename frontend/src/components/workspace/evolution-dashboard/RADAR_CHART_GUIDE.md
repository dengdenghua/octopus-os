# 多维能力雷达图 - 功能说明

## ✅ 已完成

### 核心组件
- `AbilityRadarChart` - 可复用的雷达图组件
- 集成到 `CharacterCard` - 角色卡片中展示
- 数据自动计算 - 从进化数据中提取能力维度

## 📊 功能特性

### 1. 多维度能力展示

#### 通用能力维度（6维）
```
📊 能力雷达
    ┌────────────┐
   /              \
  /   执行效率      \
 │        85        │
 │                  │
 │   准确度  创造力  │
 │    88      72    │
 │                  │
 │ 学习能力 沟通表达 │
 │   76      81     │
 │                  │
 │   问题解决       │
  \      79        /
   \              /
    └────────────┘
```

**维度说明**：
- **执行效率**：基于平均成功率
- **准确度**：基于成功率和一致性
- **创造力**：基于自动提取技能数量
- **学习能力**：基于学习事件增长率
- **沟通表达**：基于记忆数量（理解和表达能力）
- **问题解决**：综合成功率和技能多样性

#### 代码类角色专用维度（6维）
```
- 代码质量
- 问题修复
- 性能优化
- 架构设计
- 测试覆盖
- 文档完善
```

#### 设计类角色专用维度（6维）
```
- 界面设计
- 体验优化
- 原型设计
- 品牌设计
- 可访问性
- 响应式
```

### 2. 视觉设计

#### 网格背景
- 5层同心多边形网格
- 半透明边框
- 轴线从中心辐射

#### 数据展示
- **填充区域**：半透明主色（20%透明度）
- **边界线**：实线主色（2px）
- **数据点**：圆点标记每个维度值
- **标签**：维度名称 + 数值

#### 配色
- 使用主题色（`text-primary`）
- 自动适配亮色/暗色模式
- 网格和轴线使用边框色

### 3. 数据计算逻辑

#### 从进化数据提取
```typescript
calculateAbilityScores(
  data: EvolutionOverview,
  skillPerformances: SkillPerformance[],
  dimensionType: "general" | "coding" | "design"
): RadarDataPoint[]
```

#### 计算示例
```typescript
// 执行效率 = 平均成功率
efficiency = data.skills.avg_success_rate

// 创造力 = 自动技能数量 / 20 * 100
creativity = Math.min((data.skills.auto_extracted / 20) * 100, 100)

// 代码质量 = 相关技能的平均成功率
codeQuality = getSkillScore(skills, ["refactor", "代码质量", "重构"])
```

## 💡 使用场景

### 1. 快速评估
一眼看出角色的强项和弱项：
- **强项**：外围突出的点（值高）
- **弱项**：内部凹陷的点（值低）
- **平衡性**：形状是否规则

### 2. 针对性培养
根据雷达图优化培养策略：
- 发现短板 → 针对性训练
- 发挥优势 → 深度专精
- 全面发展 → 补齐弱项

### 3. 角色对比
多个角色的雷达图对比：
- 技能互补性分析
- 团队配置优化
- 角色定位明确

## 🔧 技术实现

### SVG 绘制
```typescript
// 计算点坐标
const calculatePoint = (index: number, value: number) => {
  const angle = (Math.PI * 2 * index) / data.length - Math.PI / 2;
  const distance = (value / 100) * radius;
  return {
    x: center + Math.cos(angle) * distance,
    y: center + Math.sin(angle) * distance,
  };
};

// 生成路径
const path = data
  .map((item, index) => {
    const point = calculatePoint(index, item.value);
    return `${index === 0 ? "M" : "L"} ${point.x} ${point.y}`;
  })
  .join(" ") + " Z";
```

- 纯 CSS 过渡动画

- 轻量级 SVG
