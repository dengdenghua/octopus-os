# 自进化页面优化方案

## 当前问题分析

### 1. 信息架构混乱
- **重复指标**：stages（4个阶段）和 metrics（3个指标）有内容重叠
- **交互复杂**：点击阶段卡片 → 展开详情，再点击 → 显示实际变更，逻辑跳跃
- **视觉层次不清**：同一屏幕有太多卡片（4+3+1+2=10个卡片）

### 2. 用户心智负担高
- 用户需要理解"阶段"和"指标"的区别
- 需要点击多次才能看到关键信息（实际变更）
- "选中指标 → 显示详情 → 取消选中 → 显示实际变更"的交互路径不直观

### 3. 缺少关键信息
- **时间轴视角**：什么时候学到了什么？
- **因果关系**：哪个任务导致了哪个技能的提升？
- **可操作性**：用户看完数据后应该做什么？

## 优化方案

### 方案 A：简化为"成长故事流"（推荐）

**核心思路**：像讲故事一样呈现 AI 的成长过程

#### 布局结构
```
┌─────────────────────────────────────────────┐
│  🧠 成长概览卡片（紧凑）                    │
│  已观察 23 次任务 · 形成 8 项技能 · 提出 3 条建议 │
│  [查看详细时间线 →]                         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│  📊 成长曲线（折线图）                       │
│  - 任务成功率趋势                            │
│  - 技能掌握度变化                            │
│  - 记忆积累曲线                              │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│  🎯 本周关键进展（卡片列表）                 │
│  ┌──────────────────────────────────────┐  │
│  │ ✨ 新技能：代码重构                   │  │
│  │ 来源：完成了 5 次重构任务              │  │
│  │ 成功率：80% → 提升 15%                 │  │
│  └──────────────────────────────────────┘  │
│  ┌──────────────────────────────────────┐  │
│  │ 💡 新规则：优先使用类型安全的代码      │  │
│  │ 来源：3 次类型错误的反馈               │  │
│  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│  💡 改进建议（Recommendations）              │
│  - 当前建议列表                              │
│  - 可操作按钮（采纳/忽略）                   │
└─────────────────────────────────────────────┘
```

#### 优势
- **清晰的故事线**：概览 → 趋势 → 进展 → 建议
- **减少认知负担**：不再区分"阶段"和"指标"
- **可操作性强**：直接在建议卡片上操作

### 方案 B：保留现有结构，微调优化

#### 具体改动
1. **合并 stages 和 metrics**
   - 移除右侧的 3 个 metrics 卡片
   - 在 4 个 stages 上直接显示数值和趋势

2. **默认展开"实际变更"**
   - 不需要点击才能看到关键信息
   - 将"实际变更"作为页面焦点

3. **添加快速操作**
   - 在推荐建议上添加"采纳"/"忽略"按钮
   - 一键查看详细时间线

## 推荐实施步骤

### Phase 1：信息架构优化（1-2天）
1. 移除重复的 metrics 卡片
2. 重新设计 stages 展示（添加数值和进度）
3. 默认展开"实际变更"区域

### Phase 2：交互优化（1天）
1. 简化点击交互逻辑
2. 添加快速操作按钮
3. 优化空状态提示

### Phase 3：视觉优化（1天）
1. 调整间距和卡片阴影
2. 优化颜色使用（减少渐变，增加对比）
3. 统一字体大小和行高

## 技术实现建议

### 1. 组件拆分
```typescript
// 当前：一个大组件 GrowthStoryHero
// 优化后：
- <EvolutionOverview />      // 顶部概览
- <GrowthTrendChart />        // 成长曲线
- <KeyProgressList />         // 关键进展
- <RecommendationCards />     // 改进建议
```

### 2. 状态管理简化
```typescript
// 移除复杂的选中状态
const [selectedInsightKey, setSelectedInsightKey] = useState<string | null>(null);

// 改为简单的展开/折叠
const [expandedSections, setExpandedSections] = useState<Set<string>>(new Set(['progress']));
```

### 3. 性能优化
- 使用 React.memo 缓存卡片组件
- 图表使用 lazy loading
- 时间线数据分页加载
